  `struct chimera_vfs_cred_sids` (ngroups, user, groups[]); added the
  `const struct chimera_vfs_cred_sids *sids` field to

  `chimera_vfs_cred_init_anonymous`.
- `src/vfs/sdk/vfs_module.h` -- bumped `CHIMERA_VFS_SDK_VERSION` from 2 to

- `src/vfs/vfs_cred.c` -- cleared `cred->sids = NULL` in
  `chimera_vfs_cred_init_unix` and `chimera_vfs_cred_init_attr`; added the
  same clear inside the lazy-init branch of the static server credential in
  `chimera_vfs_get_server_cred` (belt-and-suspenders: that credential is
  `static struct chimera_vfs_cred cred = { 0 };`, so `sids` is already
  NULL from the static zero-initializer, but the brief explicitly called
  out this site and the explicit line matches how the other fields are
  set there).
- `src/vfs/vfs_acl.c` -- added `cred_matches_sid()` right after
  `cred_in_group()`, and replaced the `CHIMERA_PRINCIPAL_SID` arm of
  `ace_applies()` to call it instead of unconditionally returning 0.
- `src/vfs/tests/vfs_acl_test.c` -- added `mkcred_sids()` helper and the
  two new tests `test_opaque_sid_ace_enforces` /
  `test_opaque_sid_ace_denies`, registered in `main()`. Per the task
  instructions' explicit decision #1, the ACL buffer memsets in these two
  new tests clear the *full* `ACL_BUF(acl, 4)` storage
  (`memset(acl_storage, 0, sizeof(acl_storage))`) rather than the 2-ACE
  prefix the brief's inline code showed, so `aces[2..3]` are not
  indeterminate.
- `src/server/nfs/tests/test_fh_security.c` -- added `cred.sids = NULL;`
  in `test_squash()`. This credential is built by direct field
  assignment (no initializer call, no memset), which is exactly the risk
  case decision #2 called out. `chimera_nfs_squash_cred()` (the function
  under test) never reads or writes `cred->sids`, so this could not have
  crashed the test as written, but it is a genuine gap in the "every
  cred is fully defined" invariant and the audit instructions asked to
  close gaps like this rather than reason about whether the particular
  test happens to touch the field.

  the static `= { 0 }` initializer already zeroes `sids`; I kept it

  for is now set there explicitly). If the reviewer would rather this
  one line be dropped as redundant, that's a reasonable call the other
  way.

  pre-existing tests passed on the very first attempt after Steps 3-6
  were applied, and the full quick tier (55/55) and the named extended
